# 🕹️ Text-Based Hangman Game

A simple, interactive console-based Hangman game written in Python. This project was developed as part of a Python programming assignment to demonstrate core programming fundamentals.

## 📝 Project Scope
This project follows a streamlined, console-only implementation with the following specifications:
* **Predefined Word List:** Uses a curated list of 5 words (no external APIs or file reading required).
* **Guess Limit:** The player is allowed a maximum of 6 incorrect guesses before the game ends.
* **Interface:** Completely text-based console input and output—no heavy graphics or audio.

## ⚙️ Core Concepts Demonstrated
This script showcases foundational Python programming mechanics, including:
* `random` module (for picking the secret word)
* `while` loops (to maintain the game state until a win/loss condition is met)
* `if-else` conditional statements (for evaluating user guesses and input validation)
* `strings` & `lists` (for tracking guessed letters and rendering the hidden word display)
